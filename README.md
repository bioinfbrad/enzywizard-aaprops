# EnzyWizard-AAprops


EnzyWizard-Aaprops is a command-line tool for calculating amino acid
residue properties from a cleaned protein structure and generating a detailed JSON report.
It extracts residue structural and physicochemical features, such as
residue name, chemical classification, secondary structure, relative solvent
accessibility, backbone torsion angles, and physicochemical properties predefined 
in AAindex database. It also computes overall statistics summarizing residue distribution,
chemical classification distribution, and secondary structure distribution across the protein.

# example usage:

The examples below use placeholder paths such as `path/to/cleaned_input.cif` and
`path/to/output_dir/`; replace them with your own cleaned structure file and
output directory.

Calculate amino acid properties from a cleaned CIF file using short options.

```
enzywizard-aaprops -i path/to/cleaned_input.cif -o path/to/output_dir/
```

Calculate amino acid properties from a cleaned PDB file using short options.

```
enzywizard-aaprops -i path/to/cleaned_input.pdb -o path/to/output_dir/
```

Calculate amino acid properties using long option names.

```
enzywizard-aaprops --input_path path/to/cleaned_input.cif --output_dir path/to/output_dir/
```

# input parameters:

-i, --input_path
Required.
Path to the input cleaned protein structure file in CIF or PDB format.
Supported file extensions: .cif, .pdb.

-o, --output_dir
Required.
Path to the output directory for saving the JSON report.
The output directory is created automatically if it does not exist.


# output files:

The program outputs the following files into the output directory:

`{name}` is derived from the input file name without its extension.

1. A JSON report
   - aaprops_report_{name}.json
     - JSON report containing amino acid residue properties and summary statistics.

2. A log file
   - log.txt
     - Processing log containing informational messages and errors.

# Process:

This command processes the input cleaned protein structure as follows:

1. Validate basic input conditions
   - Check that the input file exists.
   - Resolve the protein name from the input filename.

2. Load the input structure
   - Read the cleaned CIF or PDB file using Biopython (Bio.PDB).
   - Validate that the input structure satisfies the cleaned-structure requirement.

3. Load DSSP
   - Run DSSP on the cleaned structure.
   - Prepare residue-level DSSP fields, including residue secondary structure,
     relative solvent accessibility, and backbone torsion angles.

4. Calculate amino acid residue properties
   - Extract the single chain from the cleaned structure.
   - Iterate through all residues in chain order.
   - Convert each residue name into a normalized one-letter amino acid code.
   - Encode residue name into a one-hot vector.
   - Assign residue chemical classification labels and encode them into a multi-hot vector.
   - Retrieve residue secondary structure and encode it into a one-hot vector.
   - Retrieve DSSP relative solvent accessibility, phi, and psi values.
   - Attach predefined physicochemical property values, including net charge,
     pKa, volume, hydrophobicity, molecular weight, and isoelectric point.
   - Store the residue alpha carbon coordinate together with the above features.

5. Compute summary statistics
   - Count residue name occurrences across the 20 standard amino acid types.
   - Count residue chemical classification occurrences across the predefined classification categories.
   - Count residue secondary structure occurrences across the 8-state labels.

6. Save outputs
   - Generate and save a JSON report containing both amino acid
     residue properties and properties statistics.


# common errors and solutions:

- "Input not found"
  - Cause: The path passed to `-i` or `--input_path` does not exist or is not a file.
  - Solution: Check the input file path and make sure it points to an existing cleaned CIF or PDB file.

- "Filename too long"
  - Cause: The input file name without extension is longer than the supported filename limit.
  - Solution: Rename the input file to a shorter name and run the command again.

- "Unsupported format"
  - Cause: The input file extension is not `.cif` or `.pdb`.
  - Solution: Use a supported cleaned structure file format.

- "Exception in loading structure for"
  - Cause: The input file could not be parsed as a usable structure file.
  - Solution: Check that the file is valid, non-corrupted, and in CIF or PDB format.

- "Structure must contain exactly one model. Please run 'enzywizard clean' first."
  - Cause: The input structure contains zero models or multiple models.
  - Solution: Run the structure through `enzywizard-clean` first and use the cleaned output as input.

- "Structure must contain exactly one chain. Please run 'enzywizard clean' first."
  - Cause: The input structure contains zero chains or multiple chains.
  - Solution: Run the structure through `enzywizard-clean` first so the input has a single cleaned chain.

- "Cleaned structure must use chain ID 'A'. Please run 'enzywizard clean' first."
  - Cause: The input structure is not in the cleaned chain format expected by EnzyWizard-Aaprops.
  - Solution: Use the output generated by `enzywizard-clean`.

- "Non-protein or hetero residue detected"
  - Cause: The input still contains heterogens, water, ligands, or other non-protein residues.
  - Solution: Run `enzywizard-clean` first and use the cleaned CIF or PDB output.

- "Insertion code detected"
  - Cause: The input contains insertion codes and is not in the expected continuous cleaned residue numbering.
  - Solution: Run `enzywizard-clean` first and use the cleaned output.

- "Residue numbering is not continuous"
  - Cause: Residue indices do not start at 1 and continue without gaps.
  - Solution: Run `enzywizard-clean` first to renumber the structure.

- "Missing backbone atom"
  - Cause: A residue is missing a required backbone atom.
  - Solution: Run `enzywizard-clean` first. If the error remains, check the input structure quality.

- "Missing heavy atoms"
  - Cause: A residue is missing required heavy atoms.
  - Solution: Run `enzywizard-clean` first. If the error remains, inspect the residue reported in `log.txt`.

- "Unexpected heavy atoms"
  - Cause: A residue contains heavy atoms that are not expected for its standardized residue type.
  - Solution: Run `enzywizard-clean` first and check whether the input contains unusual residue records.

- "Exception in loading dssp"
  - Cause: DSSP failed to run or failed to parse the cleaned structure.
  - Solution: Confirm that DSSP or `mkdssp` is installed and available, and check that the cleaned input structure is valid.

- "DSSP key ... not found."
  - Cause: A residue in the cleaned structure could not be matched to a DSSP result.
  - Solution: Check the cleaned structure and rerun `enzywizard-clean` if residue numbering or chain records look unusual.

- "DSSP fields missing for residue"
  - Cause: DSSP did not return the fields needed to calculate residue properties.
  - Solution: Check the DSSP output and rerun `enzywizard-clean` if residue numbering or chain records look unusual.

- "Invalid DSSP numeric values"
  - Cause: DSSP returned non-numeric relative solvent accessibility, phi, or psi values for a residue.
  - Solution: Check the DSSP installation and inspect the affected residue in the cleaned input structure.

- "Unrecognized residue name"
  - Cause: A residue name could not be converted to a standard one-letter amino acid code.
  - Solution: Use a cleaned structure containing only standard amino acid residues.

- Cleaned structure validation failed
  - Cause: The input is not a valid EnzyWizard-cleaned structure. Common causes include multiple chains, non-chain-A input, heterogens, insertion codes, non-continuous residue numbering, missing atoms, or unexpected atoms.
  - Solution: Review the specific error message above this summary in `log.txt`, then rerun `enzywizard-clean` and use its cleaned output.

- Failed to load DSSP
  - Cause: DSSP could not be loaded or run successfully.
  - Solution: Check the DSSP installation and review the preceding `Exception in loading dssp` message in `log.txt`.

- Failed to calculate amino acid properties
  - Cause: The structure passed validation, but residue-level DSSP fields, residue names, or CA coordinates could not be processed.
  - Solution: Review the specific residue-level error above this summary in `log.txt`.

- Output files are missing
  - Cause: The command failed before all output files were written, or the output directory is not the one expected.
  - Solution: Check `log.txt`, confirm the `-o` output directory, and rerun after fixing earlier errors.

- Output file names are different from expected
  - Cause: Output names use `{name}`, which is derived from the input file name without its extension.
  - Solution: Check the input file name and look for `aaprops_report_{name}.json` and `log.txt` in the output directory.
